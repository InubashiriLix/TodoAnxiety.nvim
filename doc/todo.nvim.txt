1. INTRODUCTION                                                   *todo-intro*

todo.nvim manages personal tasks in one local SQLite database. It provides a
responsive floating dashboard and a sidebar with the same scopes and actions.
Neovim 0.10+, kkharji/sqlite.lua, MunifTanjim/nui.nvim, and a system SQLite
shared library are required.

Use |:checkhealth| todo to diagnose the installation.

==============================================================================
2. SETUP                                                           *todo-setup*

>lua
  require("todo").setup({
    db_path = vim.fn.stdpath("data") .. "/todo.nvim/todo.db",
    language = "en", -- or "zh-CN"
    -- Manual sync; see |todo-sync| for first-device and Mac setup.
    sync = {
      enabled = false, -- set true after configuring the private Git remote
      remote = "", -- e.g. "git@github.com:YOUR_NAME/private-todos.git"
      branch = "main", -- same remote and branch on every device
    },
    ui = {
      default_mode = "float",
      default_view = "active", -- or today, emergency, notices, archived;
                               -- by_urgency/time/tag == active + grouping
      markdown = true, -- render the detail pane and description as markdown
      float = { width = 0.80, height = 0.75, border = "rounded" },
      sidebar = { width = 42, side = "right" },
    },
    keymaps = {
      toggle = "<leader>Tt",
      add = "<leader>Ta",
      open_float = "<leader>Tf",
      open_sidebar = "<leader>Ts",
      open_emergency = "<leader>Te",
      manage_tags = "<leader>Tg",
      add_notice = "<leader>Tn",
    },
    icons = {
      toggle = { icon = "\u{f204}", color = "yellow" },
      add = { icon = "\u{f067}", color = "green" },
      open_float = { icon = "\u{eb7f}", color = "blue" },
      open_sidebar = { icon = "\u{f03c7}", color = "cyan" },
      open_emergency = { icon = "\u{f071}", color = "orange" },
      manage_tags = { icon = "\u{f02c}", color = "purple" },
      add_notice = { icon = "\u{f0f3}", color = "orange" },
    },
    reminders = {
      enabled = true,
      sound = {
        path = "/path/to/reminder.ogg",
        command = { "mpv", "--no-video", "--really-quiet" },
      },
    },
  })
<

The icons table is optional which-key.nvim v3 metadata. todo.nvim registers it
with which-key.add(), producing a separate icon column; icons are not prepended
to mapping descriptions. Strings and { icon, color } tables are accepted.

The public Lua API consists of setup(), open(opts), toggle(opts), add(opts),
notice(opts), tags(), close(), sync(), and sync_status(). Database internals
are not public API. sync() runs asynchronously and reports its result through
notifications; sync_status() returns local status and displays it.

==============================================================================
3. COMMANDS                                                     *todo-commands*

                                                             *:Todo*
:Todo [open] [float|sidebar] [view]
        Open a task view. The view is one of today, active, emergency,
        notices, or archived. by_urgency, by_time, and by_tag are accepted
        as active with that grouping. With no arguments, use configured
        defaults.

:Todo toggle [float|sidebar]
        Toggle the panel.

:Todo add [title]
        Open the task form with an optional prefilled title.

:Todo notice [title]
        Open the notice form. Relative triggers such as 30s, 5m, 2h, and 1d
        are accepted, as are exact local dates and times.

:Todo tags
        Open the tag manager. Create, rename, delete, filter, and inspect tag
        usage counts from one panel.

:Todo sync
        Download, merge, and upload changes using the configured private Git
        repository. This is the only command that contacts the remote.

:Todo sync status
        Show local pending records, last success/error, and the sync directory.
        Does not check the remote. See |todo-sync|.

:Todo edit [id]
:Todo start [id]
:Todo done [id]
:Todo cancel [id]
:Todo reopen [id]
:Todo archive [id]
:Todo restore [id]
        Operate on a task. In a todo panel, a missing ID means the task under
        the cursor. Archive is reversible.

:Todo delete [id]
        Permanently delete an archived task. Active tasks are rejected. This
        operation cannot be undone.

:Todo close
        Close the current panel.

4. MAPPINGS                                                     *todo-mappings*

Global defaults (all configurable or disableable):

  <leader>Tt   toggle dashboard            <leader>Ta   add task
  <leader>Tf   open floating panel         <leader>Ts   open sidebar
  <leader>Te   open emergency view         <leader>Tg   manage tags
  <leader>Tn   add notice

Existing mappings are not overwritten. Panel-local mappings:

  j/k          move                    gg/G   first/last row
  <C-u>/<C-d>  move half a page        <CR>   show details
  <Tab>/za     fold section            zR/zM  expand/collapse all
  a/n/e        add task/notice/edit    s      start
  x/c/u        done/cancel/reopen      A/R    archive/restore
  D            permanently delete the selected archived task (with confirm)
  p            postpone the overdue task (input defaults to 1d)
  /            search                  f      filter
  g            manage tags
  v            choose view/grouping    r      refresh
  o            change grouping         <Esc>  clear filters, else close
  [/]          previous/next scope
  ? / <F1>     contextual help         q      close
  U / <C-r>    undo / redo saved task operations

Hints follow the focused window, task state, field and editing mode. Press ?
in Normal mode or F1 in Normal/Insert mode for complete grouped, scrollable
help. Insert-mode ? remains text. Help restores focus and mode when closed.
Completed/cancelled ordinary tasks offer s (resume in_progress) and u (todo).
Archived tasks offer e/R/D; restore before changing status. Only available
operations are offered, and unavailable task keys do not modify data.

U undoes the last saved task operation; CTRL-R redoes it in the dashboard,
details and reminder popup. Up to 50 steps are kept for this Neovim session:
status changes, edits, postponement, archive/restore and reminder actions.
New changes clear redo. Undo refuses to overwrite externally modified tasks.
Creation, permanent deletion and bulk tag changes are excluded. Unsaved text
retains native Neovim undo.

The form uses CTRL-S to save, q / CTRL-Q / :q to close, and Normal + to
expand or restore the focused field. Escape never closes the form: in Insert
mode it only exits Insert, and Normal-mode Escape does not close.

Press p on an overdue task in the list, sidebar, details or reminder popup to open an input
prefilled with 1d. Enter sets the deadline to submission time plus 24 hours;
custom positive durations such as 2h, 3d, or 1d2h are also accepted. Deadlines
are rounded up to the next minute, including formerly date-only deadlines.
Existing reminders move with the deadline, preserving interval and recurrence.
Escape or CTRL-Q cancels without changes. Only unarchived ordinary tasks in
todo or in_progress status with a past deadline qualify.

The dashboard shows two-line task cards. At 100 or more available columns, the
floating view adds a fixed detail pane; narrow layouts open details with Enter.
Use [ and ] to change scope and o to change grouping; h/l move between the list
and details in a wide dashboard.
In the list, gg/G select the first/last row and Ctrl-U/Ctrl-D move by half the
visible list height. In the fixed detail pane and detail popup, j/k, gg/G and
Ctrl-U/Ctrl-D navigate detail text without changing task selection or focus.
Use l to enter the fixed detail pane and h to return to the list. The dashboard's
g mapping still opens tag management.

The detail pane and popup render the task as markdown: a field list (status,
priority, deadline, urgency, tags) followed by the description exactly as
typed. Its filetype is set to "markdown", so an installed rendering plugin
attaches automatically; otherwise Neovim's built-in treesitter highlighting
applies. Set ui.markdown = false to see the raw markdown source instead. The
form's description field uses the same filetype, so markdown typed there
highlights live and renders the same way once saved.

Known incompatibility: filetype = "markdown" means any installed markdown
rendering plugin that attaches via `FileType markdown` will also try to
render these buffers. Plugins that defer their own setup with a timer and do
not re-check buffer validity when it fires can error if the popup closes
before the timer runs (mdmath.nvim, ~100ms delay, is one such plugin).
todo.nvim shares one long-lived buffer between the fixed detail pane and the
detail overlay to shrink this race, but cannot eliminate it for every
third-party plugin. Report it upstream, or set ui.markdown = false to opt
out of filetype = "markdown" entirely.

Five scopes are available as header tabs: active, today, emergency, notices,
and archived. Active, today, and emergency can be grouped by status, urgency,
time remaining (overdue/today/this week/later/no deadline), or tag (a tree with
one root per tag plus Untagged). by_urgency/by_time/by_tag are aliases for
active with that grouping. This keeps the tab bar short while preserving every
previous view.

Every section header folds with <Tab> or za; zR expands all and zM collapses
all. Folds are remembered per view while the panel stays open, and j/k walk
section headers as well as tasks.

Escape unwinds one layer: in the search box it clears the query and returns the
cursor to the list from either mode; in a menu, help, or detail popup it closes
that window; on the list it clears active filters, or closes the panel if none
are set.

The / search input closes on WinLeave. Entering any non-todo window closes a
floating dashboard; detail, menu, search, and tag-manager windows count as
todo windows. A sidebar stays open. The dashboard blocks mouse navigation and
Ctrl-h/j/k/l locally. AI planning uses Normal-mode Ctrl-h/j/k/l for its panes;
ordinary editing buffers retain their original mappings.

The task form has separate title, priority, status, deadline, tag, and
description controls. Tab and Shift-Tab move focus, except in the description's
Insert mode where editing/completion retains both keys. Press Escape, then
Tab/Shift-Tab to switch fields from the description. Deadline selection opens a
calendar with hjkl day movement, [/]/PageUp/PageDown month movement, Enter to
choose, g for today, t for the unrestricted time editor, and x to clear. In the
time editor, type HHMM directly; h/l changes fields, j/k adjusts by one, and J/K
adjusts by five. The date, hour, and minute stay visible together; crossing
midnight automatically rolls the date. Press Enter on an empty tag field to open the tag panel. It
supports j/k movement, selection with Enter/Space, creation with a, rename with
r, deletion with d, and filtering with /. The same manager is available through
|:Todo| tags. todo.nvim registers no mouse mappings.
The priority control shows P0 through P3 directly; use 0-3, Left/Right, or
Enter to choose it. Status works the same way with 1-4. Emergency rank
itself is calculated from priority and deadline rather than entered manually.
Closing a modified form prompts to save, discard, or continue editing.
Opening a form from a dashboard suspends that dashboard and restores its view,
filters, and selection after the form closes.

The notice form has trigger, repeat interval, recurrence, tags, and description
controls. Recurrence supports once, daily, weekdays, selected weekdays, and
every N minutes, hours, or days. Press c on its trigger control for the calendar,
or t to open today's time directly. Enter advances single-line fields just like
Tab; in the multi-line description it inserts a newline. On the repeat-interval
field, t opens a days/hours/minutes/seconds duration picker; compact input such
as 5m remains available.
When a reminder fires, the forced-focus popup uses d to complete the occurrence,
s to snooze, p to postpone an overdue ordinary task (default 1d), a to archive,
and q to close only the current popup. An unhandled
item continues to remind at its configured interval. Focus, cursor, and Insert
mode are restored after handling the popup.

==============================================================================
5. EMERGENCY RANKING                                           *todo-emergency*

Candidates are unarchived todo/in_progress tasks with a deadline, plus P0/P1
tasks without a deadline.

  Deadline: overdue 120, <=24h 80, <=3d 60, <=7d 40, later 20, none 0
  Priority: P0 +30, P1 +20, P2 +10, P3 +0

Sort by score descending, then deadline presence, earlier deadline, priority,
and creation time. The UI displays a level and reason rather than the score.
Dates use local time and accept YYYY-MM-DD or YYYY-MM-DD HH:mm. Date-only
deadlines end at 23:59:59.

==============================================================================
6. DATA                                                           *todo-data*

The default database is stdpath("data")/todo.nvim/todo.db. It contains tasks,
tags, task-tag links, and numbered schema migrations. Foreign keys, WAL, a busy
timeout, and transactional migrations are enabled.

Tasks may be archived and restored. Archived tasks may also be permanently
deleted with |:Todo| delete or D in the archived view. Schema v2 stores notices,
recurrence rules, reminder state, and the last-used repeat interval. Existing
tasks remain reminder-disabled until edited with a repeat interval.

Schema v3 adds stable task UUIDs and a persistent sync journal, including when
sync is disabled. Upgrading an existing database creates a consistent backup
at <db_path>.pre-sync-<uuid>.db first. Keep this backup to use an older plugin
version. Deletion removes current rows but leaves their content in sync history.

7. MULTI-DEVICE SYNC                                               *todo-sync*

Requires Git 2.28+ on macOS or Linux. Create a dedicated private EMPTY Git
repository without a README, license, or .gitignore. Configure authentication
on each device first: SSH host verification and an agent, or an HTTPS credential
helper. Sync does not accept interactive password or host-key prompts.

On the device containing your existing todos:
>lua
  require("todo").setup({
    sync = {
      enabled = true, -- default: false
      remote = "git@github.com:YOUR_NAME/private-todos.git", -- default: ""
      branch = "main",
    },
  })
<
Run :Todo sync to publish existing data. On each additional device, install the
same plugin version, use this configuration with a fresh local database, and
run :Todo sync to download. Do not copy the old database to bootstrap devices:
independent upgrades of old database copies generate different UUIDs.

Only :Todo sync contacts the remote. Nothing syncs on startup, focus, edits, or
exit. Run it before leaving a device and after switching, or edit offline and
sync later. :Todo sync status and :checkhealth todo perform local checks only.
The managed Git directory is <db_path>.sync, separate from the plugin source.

A non-focusable progress card stays visible while syncing, showing the current
stage, elapsed time and retries. It works independently of notification plugins.
Completion remains visible for eight seconds and reports this run's uploaded
and downloaded change records, or explicitly says there are no new changes.
Pending edits made during sync are called out. Failures stay for fifteen seconds.
Final results are also recorded in :messages for later review.

Tasks, notices, tags, archives, deletions, rules, completed occurrences and
snoozes sync. Sound/UI settings, input preferences and bell delivery stay local.
Both disconnected devices can ring. Deadline text remains local time; reminder
instants are Unix timestamps. Calendar recurrence advances in the timezone of
the device completing the occurrence.

Concurrent changes select the newer WHOLE task, not individual fields. A
millisecond/logical clock plus device identity breaks ties deterministically;
incorrect device clocks can affect offline winners. UUIDs are shared, while
numeric command IDs can differ between devices. Stale forms refuse to save:
copy unsaved text and reopen the task. Recreating a deleted tag does not restore
old associations. Task deletion keeps old content in the SQLite journal and
Git history; pruning and additional application-level encryption are excluded.

Each Git process times out after 30 seconds. Concurrent push rejections retry
up to three attempts, without force pushing. Network/credential failures retain
pending records. Correct the problem and run :Todo sync again. Edits during a
sync may remain pending until the next invocation. Unknown formats, malformed
records or conflicting record IDs roll back the entire import batch.

Do not edit the managed Git directory or cloud-sync the live SQLite database.
To rebuild a missing/damaged cache, close Neovim, move <db_path>.sync aside,
then reopen and sync: the database journal rebuilds it. Preserve the database
if remote data is invalid and inspect the reported error before attempting
recovery. Keep one remote/branch per database; use a different db_path for a
different repository. Disabling sync keeps all local features available.


TODAY AND AI PLANNING                                      *todo-ai-planning*

:Todo today [YYYY-MM-DD]    Open the daily plan; deadlines stay independent.
:Todo plan [YYYY-MM-DD]     Prepare/review tasks one at a time, then draft a plan.
:Todo clarify [id]          Clarify a selected task; dashboard key Q.
:Todo ai settings           Set language/persona or enter a local API key.
:Todo ai key                Hidden API-key input; saved with file mode 0600.
:Todo ai usage              Known estimated USD and unknown-charge count.
:Todo ai balance            Query the account balance explicitly.
:Todo image {path}          Copy an image into the current Markdown editor.
:Todo diagnostics           Open redacted, rotated network diagnostics.
:Todo sync conflicts        Resolve pending server-mode conflicts.

Today keys: t toggle membership, T remove (legacy), J/K reorder, L lock, m fields, C capacity, b date,
P AI plan, Q clarify, N notes. Standard task actions and U/Ctrl-r still work.
Review: Space select, Enter compare, e edit, f feedback, a apply, t talk.
Review editor: Enter saves, + expands, Ctrl-q closes; Esc only leaves Insert.
Conversation: Enter/a/i answer, s skip, g draft now, v review, E extended changes,
V text-only mode,
+ question allowance, c cancel request. Answer editor: Normal Enter/Esc save and return, Ctrl-q cancel,
Ctrl-v paste image. Full contextual help: ? / F1.

Daily planner: preparation -> per-task review -> final draft -> approval.
All unfinished tasks are initially selected. Enter confirms locks, w starts.
a/e create/edit, Space include/exclude, L lock, C work time, B reserve.
New plans default to 480 minutes with 60 reserved; new members are unlocked.
Existing dates keep their saved settings. Full locked capacity blocks paid IO;
S explicitly continues while preserving locks.

The fixed Markdown composer is a real Vim buffer, initially Normal. Insert-mode
Enter/Tab, u/Ctrl-r, registers and Visual mode are native. Normal Enter/Esc
returns to choices; w in the choices pane previews, then Enter submits,
Ctrl-c cancels IO, Ctrl-q saves drafts and closes. Normal Ctrl-v is block selection;
Insert Ctrl-v / Normal <localleader>p paste images. Normal Ctrl-h/j/k/l switches AI panes;
Normal <localleader>q focuses options even in tiny windows. Outside the composer:
j/k selects, Space/Enter toggles options without advancing, e annotates, i types a custom answer, Tab/h/l
switches questions; g in choices (c in context) finishes with known facts,
s defers, b/d shows queue/details,
p returns to preparation, V toggles text-only, v reviews proposals, F1 shows help.

ai.planning.max_rounds_per_item=10 is a per-task/date hard cap, with at most
ai.planning.questions_per_round=3 related questions each round. Reopen/replan or
another device does not reset counts; a new date does, reusing dated reviews.
ai.planning.max_requests_per_item=16 includes lookups/repair/final requests;
max_requests_total=false derives selected task count * 16 + 2. Daily workflow
costs share ai.session_budget_usd; all workflows share ai.daily_budget_usd.
Limits pause without discarding completed reviews. Missing billing is unknown.

SSE streams only the public message; complete JSON is validated before approval.
Set ai.planning.stream=false or ai.capabilities.streaming=false for non-SSE APIs.
Closing cancels the active request and stops automatic queue advancement.
Local drafts/partial output: stdpath('state')/todo.nvim/daily-drafts (0600 files).
Date-scoped leases and checkpoint sync protect server workflows; token updates
never sync. VimResized retains buffers, drafts and request handles.

Single-task :Todo clarify retains its separate conversation settings:
ai.max_rounds=10, ai.max_questions_per_round=8 and ai.max_requests=20.

Sync defaults to manual (sync.auto=false, interval_seconds=0). Opt-in automatic
uploads are quiet and only follow local edits. Explicit polling requires both
auto=true and interval_seconds>0. Empty pulls do not schedule another upload.

:Todo ai memory manages sourced facts and pending inferences. c confirms,
p pins, e edits, d forgets, a adds, / searches. Memory scopes and input budgets
are controlled through ai.memory and ai.context_tokens. Deleted facts sync as
tombstones; derived summaries are invalidated. Local search falls back when
FTS5 is unavailable. Cloud protocol v2 rejects incompatible clients before pull.
One malformed-output repair is allowed and counted. Costs use returned token
usage and configurable rates; missing usage is unknown, not zero. API keys are
never synced. AI key lookup: ai.api_key (string/function), ai.api_key_file,
ai.api_key_env, local credentials, then official DeepSeek OpenCode/MCP fallback.
Sync authentication: sync.token (string/function), sync.token_file, sync.token_env.
Explicit broken credential sources fail closed, without using another account.

All runtime options can be set in require('todo').setup(); no settings UI is
required. ai.preferences_source='config' makes Lua language/persona authoritative.
planning.capacity_minutes, planning.reserve_minutes (false uses reserve_ratio),
and planning.timezone_offset_minutes
configure daily-plan defaults. ai.text_only and ai.extended set new-session
behavior. Existing plans and conversation counters remain persistent data.

Server data APIs require bearer tokens; only /v1/status exposes a public version.
Device tokens access one shared dataset, not isolated user accounts. Task data
is not end-to-end encrypted. See doc/security.md and doc/configuration.md.

See doc/planning.md for configuration, behavior and server setup. Server mode is
optional and mutually exclusive with Git transport. Local planning works offline.

UI navigation and editing:~
Normal + maximizes/restores the focused pane. Task editor :w saves in place;
:wq/:x saves and returns to the parent panel. :q refuses unsaved changes, and
:q! discards changes since the explicit save. In the task editor, + expands the
focused field; Escape only mode-switches, and q / CTRL-Q / :q closes. AI input Insert Enter/Tab remain
native; Esc leaves Insert, then Enter/Esc saves the draft and returns to choices.
Ctrl-Alt-u/d scroll visible AI context half a page, Ctrl-Alt-b/f a full page,
without leaving the composer. Ctrl-Alt-g resumes following the latest response.
Main Todo buffers block mouse clicks/drags and Ctrl-h/j/k/l navigation locally.
See doc/configuration.md for ui.daily_keys overrides and disabling actions.
